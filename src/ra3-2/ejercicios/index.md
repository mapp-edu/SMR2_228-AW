# 🛠️ Prácticas del RA3.2 · Gestión de archivos web y JavaScript

La **P1** monta un servicio de gestión de archivos web para la entidad de tu mini sitio. Las prácticas **P2 a P4** añaden interactividad al **mini sitio** que creaste en el RA3.1; si no lo tienes, puedes partir de una página HTML5 sencilla con estructura semántica.

| Práctica | Qué harás | CE evaluados |
|----------|-----------|--------------|
| [P1 · Gestor de archivos web](./p1-gestor-archivos) | Comparar aplicaciones, instalar y adaptar FileBrowser Quantum, crear cuentas por perfiles, gestionar archivos y comprobar la seguridad | a, b, c, d, e, f |
| [P2 · Seleccionar y modificar](./p2-seleccionar-modificar) | Clasificar los lenguajes de script, sintaxis básica, selección de elementos, modificación de contenido y atributos | g, h, i, j |
| [P3 · Lista de tareas dinámica](./p3-lista-tareas) | Crear, eliminar y dar estilo a elementos en una aplicación sencilla | j, k, l |
| [P4 · Formulario con validación](./p4-formulario) | Eventos, mensajes y resumen creados dinámicamente y estilos de validación | j, l |

## Cómo se evalúa

| Nivel | Descripción | Nota |
|:-----:|-------------|:----:|
| **0** | No entregado o sin relación con lo solicitado. | 0 |
| **1** | Incompleto o incorrecto. Faltan elementos esenciales. | 2,5 |
| **2** | Correcto y completo, pero sin justificar las decisiones. | 5 |
| **3** | Correcto, completo y justificado. | 7,5 |
| **4** | Además, coherente con el resto del proyecto y bien comunicado. | 10 |

::: warning-box Mínimo para superar
El **nivel 2** es el mínimo para superar cualquier instrumento. La nota de cada práctica es la media de sus criterios y ninguno puede quedar por debajo del nivel 2. Si un CE se evalúa en varias prácticas, su nota es la media.
:::

## Formato de entrega

**P1:** PDF con explicaciones, tablas y capturas, y ZIP con los ficheros de configuración (sin contraseñas ni claves).

**P2 a P4:**

- ZIP con los ficheros (`index.html`, `css/`, `js/`) y un PDF con explicaciones y capturas (incluida la **consola** sin errores).
- El código JavaScript debe ir en **ficheros externos**, con `defer` y **comentado**.
- "Justificar" significa explicar **por qué** eliges un método (por ejemplo, `textContent` frente a `innerHTML`, o `classList` frente a `style`).
