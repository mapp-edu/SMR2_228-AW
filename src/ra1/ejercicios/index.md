# 🛠️ Prácticas del RA1 · Gestores de contenidos

Las tres prácticas forman **un único proyecto**: montarás el sitio web de una entidad (tu centro, una asociación, un club…) sobre WordPress, y cada práctica parte del resultado de la anterior.

| Práctica | Qué harás | CE evaluados |
|----------|-----------|--------------|
| [P1 · Instalación de WordPress](./p1-instalacion) | Requisitos, instalación en Linux y Windows, pruebas | a, d, i |
| [P2 · Usuarios, apariencia y menús](./p2-usuarios-personalizacion) | Roles, tema, extensiones, menús y RSS | b, c, f, i |
| [P3 · Foro, seguridad y copias](./p3-foro-seguridad-copias) | Foro con reglas de acceso, actualizaciones, seguridad, backup y restauración | e, g, h, i, j |

## Cómo se evalúa

Cada criterio de evaluación (CE) se puntúa con la misma escala de **0 a 4**:

| Nivel | Descripción | Nota |
|:-----:|-------------|:----:|
| **0** | No entregado o sin relación con lo solicitado. | 0 |
| **1** | Incompleto o incorrecto. Faltan elementos esenciales. | 2,5 |
| **2** | Correcto y completo, pero sin justificar las decisiones. | 5 |
| **3** | Correcto, completo y justificado. | 7,5 |
| **4** | Además, coherente con el resto del proyecto y bien comunicado. | 10 |

::: warning-box Mínimo para superar
El **nivel 2** es el mínimo para superar cualquier instrumento. La nota de cada práctica es la media de sus criterios; para superarla, **ningún criterio puede quedar por debajo del nivel 2**.
:::

::: info-box Criterios d e i
Los criterios d e i del RA1 se refieren ambos a **pruebas de funcionamiento**. El d se evalúa en la P1 (pruebas de la instalación) y el i en cada práctica (pruebas de lo configurado); la nota del CE i es la media de las tres prácticas.
:::

## Formato de entrega

- Un **documento PDF** (o un enlace a un documento compartido) con portada, índice y un apartado por cada tarea.
- Cada tarea incluye: **qué haces, cómo lo haces** (comandos o pasos), **evidencia** (captura en la que se vea tu nombre de usuario o el nombre de tu sitio) y **por qué** tomas esa decisión.
- Las capturas deben ser legibles y llevar pie explicativo.
